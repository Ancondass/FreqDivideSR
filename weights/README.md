# weights

Place the pretrained checkpoints here before running the evaluation scripts:

- `ckpt_x2.pth` (×2 model)
- `ckpt_x3.pth` (×3 model)
- `ckpt_x4.pth` (×4 model)

See the main README for how to obtain the checkpoints during the anonymous
review period. The checkpoints are intentionally excluded from this repository.
